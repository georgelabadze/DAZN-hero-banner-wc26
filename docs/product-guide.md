# Product Guide: DAZN Hero Banner WC26

This is the hero copy and module guidance for Product review. The goal is one clear story at a time.

## Copy limits
- Larger title: about `32` characters including spaces, max `2` lines
- Large title: about `48` characters including spaces, max `2` lines
- Subtitle: about `70` characters, max `3` lines
- Label: about `24` characters
- Helper text: about `72` characters
- CTA labels: keep short, ideally `1–3` words
- Price: no strict character cap; keep it as short structured pricing, not sentence copy

## Module usage

**Title**
- **Use when:** the hero needs one clear message that can carry the whole promotion on its own.
- **Avoid when:** the headline becomes too long, wraps awkwardly, or needs the subtitle to explain what it really means.
- **Impact:** the title sets the hierarchy for the whole stack and controls how much room remains for every module below it.

**Subtitle**
- **Use when:** one supporting layer of context helps the title land faster.
- **Avoid when:** it repeats the headline, reads like paragraph copy, or pushes the stack too deep.
- **Impact:** it adds clarity, but it is also the easiest module to overuse, so shorter copy keeps the banner cleaner across breakpoints.

**Logo**
- **Use when:** the property or event brand adds recognition and helps the hero scan faster.
- **Avoid when:** the artwork already contains logos, badges, or detailed marks, or when the brand signal adds no useful meaning.
- **Impact:** it adds immediate brand context above the label, but it also increases visual density in the top part of the stack.

**Label**
- **Use when:** a short event date, season range, promo note, or offer cue improves scanning before the title.
- **Avoid when:** the title already says the same thing or the message is too long to stay lightweight.
- **Impact:** it introduces context without changing the main hierarchy, as long as it stays short and genuinely useful.

**Price**
- **Use when:** pricing is part of the value proposition and helps qualify the offer immediately.
- **Avoid when:** the same message is already carried by the title or when pricing needs too much explanation to make sense.
- **Impact:** it supports short structured pricing, such as prefix, value, optional old price, and short suffix, but it should stay a value cue, not become the headline.

**CTA**
- **Use when:** one clear primary action is enough to move the user forward.
- **Avoid when:** the CTA becomes descriptive copy instead of a short action, or when two different paths need to be presented.
- **Impact:** single CTA is the default pattern and keeps the decision simple, especially on smaller screens.

**Dual CTA + Best value**
- **Use when:** the hero needs two genuinely distinct actions or offer paths and one option should be clearly emphasized.
- **Avoid when:** the second button adds choice without adding meaning, or when the stack is already visually heavy.
- **Impact:** the gold button is the emphasized option, and `Best value` is an optional note under that gold CTA only, but the dual pattern adds more decision weight and more vertical footprint on mobile.

**Helper text**
- **Use when:** extra conditions, rights notes, or legal clarifications are required but should stay visually secondary to the CTA.
- **Avoid when:** the text is non-essential, marketing-led, or only adds visual weight without reducing user uncertainty.
- **Impact:** it extends the vertical footprint of the bottom content stack, so it should only be used when the extra context is genuinely necessary.

**PPV badge**
- **Use when:** PPV status needs to be understood immediately and should be visible outside the main copy stack.
- **Avoid when:** it is redundant with the copy or competes with an already busy creative.
- **Impact:** it acts as a top-right commercial signal rather than part of the content stack, so it should stay reserved for cases where PPV is a key part of the proposition.

## Presentation vs content
- **Content decisions:** Title, subtitle, logo, label, price, CTA pattern, helper text, and PPV badge are the parts Product should actively choose.
- **Presentation/system choices:** Alignment, Gold/Standard theme, and Larger/Large title are display choices that shape how the same story is presented.
- **Demo-only tools:** Carousel, Creative Blueprint, and the slide editor help review the banner, but they are not production product UI requirements.

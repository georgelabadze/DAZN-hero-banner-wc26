Product Development

Product

Use the modules deliberately so the hero tells one clear story at a time.

The live demo exposes multiple switches, but product decisions should not be made switch by switch. Choose only the modules that materially improve clarity, hierarchy, or confidence for the user.

What good hero composition looks like

  • Keep one dominant message in the title and use the rest of the stack to support it.
  • Every added module should either improve clarity or add essential context.
  • If a module repeats information already visible elsewhere, it should usually be removed.
  • Shorter stacks travel better across desktop, tablet, and mobile.

What to avoid

  • Using every available module just because the space exists.
  • Turning the subtitle into body copy or legal copy.
  • Adding badges, logos, and helper text when the creative is already busy.
  • Letting lower-priority details compete with the title or CTA.

Modules

Use each module for a specific job.

These are the approved hero content modules for the current product implementation. Treat them as purposeful building blocks, not optional decoration.

Copy limits

  • Larger title: up to about 32 characters including spaces.
  • Large title: up to about 48 characters including spaces.
  • Subtitle: about 70 characters, assuming the creative tolerates up to 3 lines on desktop.
  • Label: about 24 characters.
  • Helper text: about 72 characters.

Title

Use when
The hero needs one clear message that can carry the full value of the promotion on its own.
Avoid when
The headline becomes too long, wraps awkwardly, or needs the subtitle to explain what it really means.
Impact
The title sets the hierarchy for the whole stack and determines how much room remains for every other module below it.

Subtitle

Use when
You need one supporting layer of context that helps the title land without turning the hero into a text block.
Avoid when
The subtitle repeats the headline, starts reading like paragraph copy, or pushes the content stack too deep for the creative.
Impact
It explains the headline, but it is also the easiest module to overuse. Short, specific copy keeps the banner cleaner across all breakpoints.

Logo

Use when
The property or event brand adds recognition and helps the hero scan faster.
Avoid when
The artwork already contains logos, badges, or detailed marks, or when the brand signal does not add useful meaning.
Impact
It adds instant brand context above the label, but it also increases visual density in the most crowded part of the content stack.

Label

Use when
You need a short event date, season range, promo note, or offer cue that improves scanning before the title.
Avoid when
The title already carries the same information or the message is too long to stay lightweight.
Impact
It introduces context without changing the main hierarchy, as long as it stays short and genuinely useful.

Helper text

Use when
Extra conditions, rights notes, or legal clarifications are required but should stay visually secondary to the CTA.
Avoid when
The text is non-essential, marketing-led, or only adds visual weight without reducing user uncertainty.
Impact
It extends the vertical footprint of the bottom content stack, so it should only be used when the extra context is genuinely necessary.

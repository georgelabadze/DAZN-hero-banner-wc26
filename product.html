Product

Use the modules deliberately so the hero tells one clear story at a time.

This page is the product handoff for the live hero component set. Use it to decide which modules belong in the story, how much copy the banner can hold, and which controls are only presentation or demo tools.

What good product review looks like

  • Keep one dominant message in the title and let the rest of the stack support it.
  • Choose only the modules that improve clarity, hierarchy, or confidence.
  • Treat CTA pattern, price, and PPV status as part of the story, not decoration.
  • Review the same stack across desktop, tablet, and mobile before calling it done.

What not to treat as product requirements

  • Not every switch in the demo represents a required product module.
  • Carousel, Creative Blueprint, and the slide editor are review tools, not production UI.
  • Alignment, theme, and title size are presentation/system choices.
  • Avoid repeating the same message across title, label, subtitle, and helper text.

Modules

Use each module for a specific job.

These are the live hero modules Product can evaluate today. Treat them as purposeful building blocks, not optional decoration.

Copy limits

  • Larger title: about 32 characters including spaces, max 2 lines.
  • Large title: about 48 characters including spaces, max 2 lines.
  • Subtitle: about 70 characters, max 3 lines.
  • Label: about 24 characters.
  • Helper text: about 72 characters.
  • CTA labels: keep short, ideally 1–3 words.
  • Price: no strict character cap; keep it as short structured pricing, not sentence copy.

Title

Use when
The hero needs one clear message that can carry the full value of the promotion on its own.
Avoid when
The headline becomes too long, wraps awkwardly, or needs the subtitle to explain what it really means.
Impact
The title sets the hierarchy for the whole stack and determines how much room remains for every other module below it.

Subtitle

Use when
One supporting layer of context helps the title land faster.
Avoid when
It repeats the headline, reads like paragraph copy, or pushes the stack too deep.
Impact
It adds clarity, but it is also the easiest module to overuse, so shorter copy keeps the banner cleaner across breakpoints.

Logo

Use when
The property or event brand adds recognition and helps the hero scan faster.
Avoid when
The artwork already contains logos, badges, or detailed marks, or when the brand signal does not add useful meaning.
Impact
It adds instant brand context above the label, but it also increases visual density in the most crowded part of the content stack.

Label

Use when
You need a short event date, season range, promo note, or offer cue that improves scanning before the title.
Avoid when
The title already carries the same information or the message is too long to stay lightweight.
Impact
It introduces context without changing the main hierarchy, as long as it stays short and genuinely useful.

Price

Use when
Pricing is part of the value proposition and helps qualify the offer immediately.
Avoid when
The same message is already carried by the title or when pricing needs too much explanation to make sense.
Impact
It supports short structured pricing, such as prefix, value, optional old price, and short suffix, but it should stay a value cue, not become the headline.

CTA

Use when
One clear primary action is enough to move the user forward.
Avoid when
The CTA becomes descriptive copy instead of a short action, or when two different paths need to be presented.
Impact
Single CTA is the default pattern and keeps the decision simple, especially on smaller screens.

Dual CTA + Best value

Use when
The hero needs two genuinely distinct actions or offer paths and one option should be clearly emphasized.
Avoid when
The second button adds choice without adding meaning, or when the stack is already visually heavy.
Impact
The gold button is the emphasized option, and Best value is an optional note under that gold CTA only, but the dual pattern adds more decision weight and more vertical footprint on mobile.

Helper text

Use when
Extra conditions, rights notes, or legal clarifications are required but should stay visually secondary to the CTA.
Avoid when
The text is non-essential, marketing-led, or only adds visual weight without reducing user uncertainty.
Impact
It extends the vertical footprint of the bottom content stack, so it should only be used when the extra context is genuinely necessary.

PPV badge

Use when
PPV status needs to be understood immediately and should be visible outside the main copy stack.
Avoid when
It is redundant with the copy or competes with an already busy creative.
Impact
It acts as a top-right commercial signal rather than part of the content stack, so it should stay reserved for cases where PPV is a key part of the proposition.

Guidance

Separate content decisions from presentation controls.

Content decisions

  • Title, subtitle, logo, label, price, CTA pattern, helper text, and PPV badge are the parts Product should actively choose.
  • These modules define the story, hierarchy, and commercial clarity of the hero.

Presentation vs demo tools

  • Alignment, Gold/Standard theme, and Larger/Large title are presentation or system choices.
  • Carousel, Creative Blueprint, and the slide editor help review the banner, but they are not production product UI requirements.
